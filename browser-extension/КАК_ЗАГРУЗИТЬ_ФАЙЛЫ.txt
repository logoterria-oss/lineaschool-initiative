  ИНСТРУКЦИЯ: Как загрузить шрифты и иконки в poehali.dev
═══════════════════════════════════════════════════════════


📁 ШАГ 1: СКАЧАТЬ ШРИФТ OpenDyslexic
─────────────────────────────────────

1. Откройте в браузере: https://opendyslexic.org/

2. Нажмите кнопку "Download" (Скачать)

3. Распакуйте скачанный ZIP-архив

4. Найдите файлы шрифта (обычно в папке с расширением .ttf или .otf)


📤 ШАГ 2: ЗАГРУЗИТЬ ШРИФТЫ В ПРОЕКТ
───────────────────────────────────

ВАРИАНТ А: Через редактор poehali.dev

1. В редакторе poehali.dev нажмите "Скачать → Подключить GitHub" 
   (если ещё не подключили)

2. После подключения GitHub:
   - Склонируйте репозиторий на свой компьютер
   - Добавьте файлы шрифта в папку browser-extension/fonts/
   - Сделайте commit и push в GitHub
   - poehali.dev автоматически синхронизирует изменения


ВАРИАНТ Б: Конвертация онлайн

Если у вас файлы .ttf или .otf, конвертируйте их:

1. Откройте: https://cloudconvert.com/ttf-to-woff2
2. Загрузите файл OpenDyslexic-Regular.ttf
3. Скачайте результат OpenDyslexic-Regular.woff2
4. Повторите для всех начертаний (Regular, Bold, Italic, Bold-Italic)

5. Также конвертируйте в WOFF: https://cloudconvert.com/ttf-to-woff

6. Загрузите все файлы через GitHub в папку browser-extension/fonts/

🎨 ШАГ 3: СОЗДАТЬ ИКОНКИ
────────────────────────

ВАРИАНТ А: Попросить Юру создать иконки

Просто напишите в чат:
"Юра, создай иконки для расширения"

Юра автоматически сгенерирует 4 иконки нужных размеров.


ВАРИАНТ Б: Создать самостоятельно

1. Используйте любой графический редактор (Figma, Photoshop, Canva)

2. Создайте 4 изображения:
   - 16x16 пикселей → сохранить как icon16.png
   - 32x32 пикселей → сохранить как icon32.png
   - 48x48 пикселей → сохранить как icon48.png
   - 128x128 пикселей → сохранить как icon128.png

3. Дизайн иконки:
   - Можно использовать эмодзи 📖
   - Или букву "А" на зелёном фоне (#2ECC71)
   - В стиле ЛинэяСкул

4. Загрузите через GitHub в папку browser-extension/icons/


⚙️ ШАГ 4: УСТАНОВИТЬ РАСШИРЕНИЕ В БРАУЗЕР
──────────────────────────────────────────

1. Подключите GitHub (если ещё не подключили)

2. Скачайте код проекта на компьютер:
   - Клонируйте репозиторий
   - Или нажмите "Скачать → Скачать код" в редакторе

3. Откройте Chrome/Edge и введите: chrome://extensions/

4. Включите "Режим разработчика" (справа вверху)

5. Нажмите "Загрузить распакованное расширение"

6. Выберите папку browser-extension из скачанного проекта

7. Готово! Расширение установлено


🎯 БЫСТРЫЙ СПОСОБ (рекомендуется)
──────────────────────────────────

1. Напишите Юре: "Создай иконки для расширения"

2. Подключите GitHub и скачайте проект

3. Скачайте шрифты с opendyslexic.org

4. Конвертируйте в WOFF2/WOFF онлайн

5. Добавьте файлы в папку fonts через GitHub

6. Установите расширение в браузер


❓ ВОПРОСЫ?
───────────

Если что-то непонятно - просто напишите в чат, Юра поможет!
