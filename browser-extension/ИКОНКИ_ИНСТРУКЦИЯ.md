# Инструкция по созданию иконок для расширения

## У вас уже есть готовый дизайн!

Иконка с открытой книгой на зелёном фоне - отличный выбор для расширения OpenDyslexic.

## Как создать 4 размера иконки

### Вариант 1: Через онлайн-редактор (быстро)

1. Откройте ваше изображение в **Figma** (бесплатно):
   - Зайдите на figma.com
   - Создайте новый файл
   - Перетащите вашу иконку
   - Измените размер на 128x128px
   - Экспортируйте как PNG → `icon128.png`
   - Повторите для размеров: 48x48, 32x32, 16x16

2. Или используйте **Canva**:
   - canva.com
   - "Настраиваемый размер"
   - Загрузите иконку
   - Измените размер и скачайте

### Вариант 2: Автоматическая конвертация

Используйте онлайн-сервис для изменения размера:

**iloveimg.com/resize-image**
1. Загрузите вашу иконку
2. Выберите размер в пикселях
3. Создайте 4 файла:
   - 16x16 → icon16.png
   - 32x32 → icon32.png
   - 48x48 → icon48.png
   - 128x128 → icon128.png

### Вариант 3: Через Photoshop/GIMP

1. Откройте изображение
2. Image → Image Size (или Изображение → Размер)
3. Установите 128x128 пикселей
4. Сохраните как icon128.png
5. Повторите для остальных размеров

## Где разместить иконки

Загрузите готовые файлы в папку:
```
browser-extension/icons/
  ├── icon16.png
  ├── icon32.png
  ├── icon48.png
  └── icon128.png
```

## Альтернатива: Попросить Юру

Просто напишите в чат:
"Юра, используй мою иконку и создай 4 размера для расширения"

Я автоматически создам все нужные размеры и добавлю их в проект.

---

**Важно:** Иконки должны быть в формате PNG с прозрачным фоном или с зелёным (#52B788) как у вас.
