ИНСТРУКЦИЯ ПО УСТАНОВКЕ РАСШИРЕНИЯ OpenDyslexic
================================================

ШАГ 1: СКАЧАТЬ ШРИФТЫ
----------------------

1. Перейдите на сайт: https://opendyslexic.org/
2. Скачайте шрифт OpenDyslexic (кнопка Download)
3. Распакуйте архив

4. Создайте папку "fonts" внутри папки "browser-extension"
5. Скопируйте файлы шрифтов в эту папку

Нужные файлы (или конвертируйте TTF в WOFF2/WOFF):
   - OpenDyslexic-Regular.woff2
   - OpenDyslexic-Regular.woff
   - OpenDyslexic-Bold.woff2
   - OpenDyslexic-Bold.woff
   - OpenDyslexic-Italic.woff2
   - OpenDyslexic-Italic.woff
   - OpenDyslexic-Bold-Italic.woff2
   - OpenDyslexic-Bold-Italic.woff

Конвертация TTF → WOFF2/WOFF (если нужно):
   - Используйте: https://cloudconvert.com/ttf-to-woff2
   - Или: https://cloudconvert.com/ttf-to-woff


ШАГ 2: СОЗДАТЬ ИКОНКИ
----------------------

Создайте 4 иконки (можно использовать любой графический редактор):

browser-extension/icons/icon16.png   (16x16 пикселей)
browser-extension/icons/icon32.png   (32x32 пикселей)
browser-extension/icons/icon48.png   (48x48 пикселей)
browser-extension/icons/icon128.png  (128x128 пикселей)

Можно использовать эмодзи 📖 или создать простую иконку с буквой "А".


ШАГ 3: УСТАНОВИТЬ В БРАУЗЕР
----------------------------

CHROME / EDGE:

1. Откройте браузер
2. Введите в адресной строке:
   - Chrome: chrome://extensions/
   - Edge: edge://extensions/

3. Включите "Режим разработчика" (переключатель в правом верхнем углу)

4. Нажмите кнопку "Загрузить распакованное расширение"

5. Выберите папку "browser-extension"

6. Готово! Расширение установлено


FIREFOX:

1. Откройте Firefox
2. Введите в адресной строке: about:debugging#/runtime/this-firefox

3. Нажмите "Загрузить временное дополнение"

4. Выберите файл "manifest.json" из папки "browser-extension"

5. Готово! Расширение установлено


ШАГ 4: ИСПОЛЬЗОВАНИЕ
---------------------

1. Нажмите на иконку расширения в панели инструментов
2. Включите переключатель "Включить шрифт"
3. Страница перезагрузится с шрифтом OpenDyslexic
4. Для отключения - нажмите переключатель снова


РЕШЕНИЕ ПРОБЛЕМ
---------------

Шрифт не меняется:
  → Проверьте, что папка "fonts" создана и содержит файлы шрифтов
  → Перезагрузите расширение в chrome://extensions/
  → Очистите кеш браузера (Ctrl+Shift+Delete)

Расширение не устанавливается:
  → Убедитесь, что включен "Режим разработчика"
  → Проверьте, что выбрана правильная папка "browser-extension"
  → Проверьте, что файл manifest.json находится в корне папки

Иконки не отображаются:
  → Создайте папку "icons" в "browser-extension"
  → Добавьте файлы icon16.png, icon32.png, icon48.png, icon128.png
